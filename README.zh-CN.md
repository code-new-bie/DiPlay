# DiPlay

**语言：** [English](README.md) · 简体中文

为兼容安卓车机提供有线及无线 CarPlay，采用 DiAuto 风格界面。

[下载与中文网站](https://code-new-bie.github.io/DiPlay/zh-Hans/) · [0.2.0 发布页](https://github.com/code-new-bie/DiPlay/releases/tag/v0.2.0) · [完整说明](README.md) · [报告问题](https://github.com/code-new-bie/DiPlay/issues/new/choose)

## 0.2.0 公开预览版

请安装在车机上，而非 iPhone。无需越狱、转接盒或认证服务器。有线模式支持 Android 9 及以上；Wi-Fi Direct 模式需要 Android 10 及以上，也可在兼容车机上选择已有的车载热点。

- 在已验证固件的比亚迪 HUD 上显示导航箭头、距离和道路名称；其他车机的支持情况取决于固件。
- 改善 Wi-Fi Direct 连接，并支持配置车载热点。偶发音频中断仍可能出现。
- 提供显示尺寸、分辨率、帧率和音乐缓冲设置，以及本地诊断报告。
- 应用界面提供简体中文与英文，跟随系统语言。

本项目未经 Apple 认证。认证使用从公开固件中提取的实验性配件身份，未来能否持续使用无法保证；部分车机仍可能卡顿或无法应用图标大小设置。HUD 的已验证固件和清除限制见 [比亚迪导航说明](docs/BYD_NAVIGATION.zh-CN.md)。源代码、构建说明及许可证随版本提供。
