# 比亚迪导航显示

在受支持的比亚迪显示设备上，可以显示手机导航的转向箭头、下一转弯距离和道路名称。日常使用不需要 ADB、root、电脑或辅助进程。地图应用必须提供结构化导航数据；并非所有地图应用及版本都兼容。

## 已验证的前挡风玻璃 HUD 路径

在 DiLink 5.1 / Android 13、固件 `BYD-AUTO/IVI/IVI:13/TP1A.220624.014/eng.build20260722.221155:user/release-keys` 上，DiAuto 和 DiPlay 的实时导航及道路名称均经过实车验证。独立 HUD 输出仅对该固件及已验证的原厂接收器版本 10601004 和签名证书启用；此结果不代表其他固件也受支持。现有仪表盘和 SOME/IP 输出仍可在支持相应原厂服务的车机上使用。DiPlay 的贡献者另行报告了 DiLink 5.0 仪表盘/HUD 的运行情况。

应用以普通 Android UID 向原厂 ClusterDebug 接收器发送仅包含导航数据的广播。向车厂接口输出的工作在手机控制回调之外执行。道路文字使用已安装 HAL 的 UTF-16LE 分块协议，最多 48 个 UTF-16 码元，且不会拆开代理项对。输出日志不记录道路文字。

路线正常结束、连接断开、关闭导航输出或导航数据过期时，应用会发送清除指令。强制停止应用或结束进程后，最后一条导航指令可能一直显示到应用再次打开；恢复记录会在下次启动时尝试清除。应用无法保证进程结束后自动清除。请勿同时运行多个投屏应用。

可在设置中控制比亚迪导航输出。DiAuto 的“导航”设置需手动开启；DiPlay 在检测到可用输出时默认开启。仅用于调试的接收器和演示功能需要 Android 的 DUMP 权限，正式版清单不包含它们。开发用启动器和车厂权限实验不属于正式导航路径。
